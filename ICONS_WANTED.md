# Icons wanted

UI chrome icons the addon looks for under `icons/ui/<name>.png`. **All are
optional** — every spot draws a clean text/color fallback until the file
exists, so generate at leisure and just drop the files in (no code change,
no regeneration needed).

Same visual language as the spell sprites, please — halo style where noted.

| File | Size | Where it shows |
|---|---|---|
| `ui/logo-64.png` | 64×64 | window header (drawn at 22px) — a Bludex mark, e.g. an open blue grimoire |
| `ui/slot-empty-64.png` | 64×64 | empty set slot in the Sets tab — a dim empty socket/frame, halo style |
| `ui/tab-codex-24.png` | 24×24 | Codex tab button (future) — a book / magnifier |
| `ui/tab-sets-24.png` | 24×24 | Sets tab button (future) — a 4×5 grid |
| `ui/tab-traits-24.png` | 24×24 | Traits tab button (future) — an upward ladder / chevrons |
| `ui/badge-unbridled-16.png` | 16×16 | marks the Unbridled spells (Harden Shell, Pyric Bulwark, Carcharian Verve, Thunderbolt) |
| `ui/badge-verify-16.png` | 16×16 | marks rows with unverified data (small "?") |
| `ui/element-Fire-16.png` | 16×16 | element badge — likewise `Ice`, `Wind`, `Earth`, `Thunder`, `Water`, `Light`, `Dark`, `None` |
| `ui/type-Physical-16.png` | 16×16 | spell-kind badge — likewise `Magical`, `Breath` |
